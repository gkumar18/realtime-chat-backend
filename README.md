# Realtime Chat Backend

## Objective
Design and build a production-grade realtime chat backend.

## Core Features
- User authentication (JWT)
- One-to-one messaging
- WebSocket-based realtime communication
- Message persistence
- Online/offline presence

## Tech Stack
- NestJS
- MongoDB
- Socket.IO
- JWT

## Design Focus
- Clean architecture
- Proper data modeling
- Separation of concerns

## Why this project?
To move beyond CRUD and develop strong backend system design skills.
